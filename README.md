# E-commerce

E‑commerce система на Python 3.12: модели товаров и категорий, загрузка данных из JSON, базовая бизнес‑логика и валидация.

Проект демонстрирует применение ООП в прикладном сценарии: инкапсуляцию данных, режимы доступа, использование `@property` и сеттеров с валидацией, а также класс-методы. Реализована устойчивая обработка некорректных данных при загрузке из JSON.

## Что реализовано в рамках ДЗ 14.2 («Режимы доступа») и ДЗ 16.1 («Магические методы»)

В проекте последовательно применены принципы инкапсуляции и контроля доступа:

- **Приватные атрибуты**:
  - `__price` в классе `Product` — защищает цену от прямого присваивания.
  - `__products` в классе `Category` — скрывает внутреннее хранение списка товаров.
- **`@property` и сеттеры с валидацией**:
  - Свойство `price` проверяет, чтобы цена была строго больше 0.
  - При снижении цены выводится предупреждение (демонстрация бизнес-логики в сеттере).
- **Класс-метод `Product.new_product()`**:
  - Позволяет создавать объект `Product` из словаря (удобно при загрузке из JSON).
- **Магические методы**:
  - `__add__` и `__radd__` в классе `Product` — реализуют сложение товаров по общей стоимости.
  - `__str__` для `Product` и `Category` — обеспечивают читаемое строковое представление объектов.
- **Методы и свойства категории**:
  - `add_product()` — добавление товара с проверкой типов.
  - Свойство `products` — безопасный доступ к списку товаров.
  - Атрибут `product_count` — вычисление количества товаров в категории.
- **Обработка некорректных данных**:
  - При загрузке из JSON битые или неполные записи пропускаются без падения программы.
  - Валидация типов и обязательных полей выполняется на уровне моделей.

## Возможности системы

- Загрузка категорий и товаров из JSON‑файла.
- Автоматическая фильтрация некорректных записей (неверные типы, отсутствие обязательных полей).
- Модели `Product` и `Category` с базовой бизнес-логикой: подсчёт общей стоимости, вывод списка товаров.
- Подсчёт статистики по категориям и товарам.
