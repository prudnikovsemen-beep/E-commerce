# E-commerce (Python 3.12)

Учебный проект по теме **«Наследование, полиморфизм, магические методы и обработка исключений»**.  
Реализована гибкая иерархия товаров с инкапсуляцией, валидацией данных, обработкой ошибок и поддержкой загрузки из JSON. Проект разрабатывается по методологии TDD: тесты пишутся до реализации логики, покрытие кода — более 87%.

## Реализованный функционал

- **Иерархия классов и наследование:** базовый класс `Product` (с миксином логирования) и специализированные подклассы `Smartphone` и `LawnGrass`.
- **Полиморфизм:** переопределение методов `describe()` и реализация специфичного поведения для разных типов товаров.
- **Инкапсуляция:** приватные атрибуты (цена, характеристики) с использованием `@property` и валидирующих сеттеров (отклонение нулевых и отрицательных цен).
- **Обработка исключений:** валидация входных данных в конструкторе и сеттерах; выброс `ValueError` при недопустимых значениях (например, `quantity == 0` или `price <= 0`).
- **Магические методы:** полная реализация интерфейса контейнера и строкового представления:
  - `__str__` — читаемое описание товара;
  - `__len__`, `__contains__`, `__iter__` — работа с категориями как с коллекциями;
  - `__add__` — объединение товаров (суммирование цены и количества).
- **Управление состоянием:** глобальные счётчики категорий и товаров в классе `Category`, корректное обновление при добавлении продуктов.
- **Работа с данными:** загрузка и валидация товаров из JSON-файлов через модуль `json_loader` (обработка ошибок, пустых файлов, неверной структуры).
