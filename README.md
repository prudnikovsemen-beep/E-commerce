# E-commerce (Python 3.12)

Учебный проект по теме **«Наследование, полиморфизм и магические методы»**.  
Реализована гибкая иерархия товаров с инкапсуляцией, валидацией данных и поддержкой загрузки из JSON. Проект разрабатывается по методологии TDD: тесты пишутся до реализации логики, покрытие кода — более 89%.

## Реализованный функционал

- **Иерархия классов:** базовый класс `Product` и специализированные подклассы `Smartphone` и `LawnGrass`.
- **Наследование и полиморфизм:** переопределение методов для специфичного поведения разных типов товаров.
- **Инкапсуляция:** приватные атрибуты (цена, характеристики) с использованием `@property` и валидирующих сеттеров (отклонение нулевых и отрицательных цен).
- **Магические методы:** полная реализация интерфейса контейнера и строкового представления:
  - `__str__` — читаемое описание товара;
  - `__len__`, `__contains__`, `__iter__` — работа с категориями как с коллекциями;
  - `__add__` — объединение товаров или категорий.
- **Управление состоянием:** глобальный счётчик товаров в категории с изоляцией состояния между тестами (фикстуры в `conftest.py`).
- **Работа с данными:** загрузка и валидация товаров из JSON-файлов через модуль `json_loader` (обработка ошибок, пустых файлов, неверной структуры).

Покрытие функционального кода — **>89%** (требование >75% выполнено с запасом).

> **Как посмотреть отчёт о покрытии:**  
> Папка `htmlcov` исключена из репозитория, так как это артефакт сборки (генерируется при каждом запуске тестов).  
> Чтобы получить актуальный отчёт, выполните:
> ```bash
> poetry run pytest --cov=src --cov-report=html
> ```
> После выполнения откройте файл `htmlcov/index.html` в браузере, чтобы увидеть детализацию по строкам и файлам.

## Запуск и проверки

Для работы с проектом используйте Poetry:

```bash
# Установка зависимостей
poetry install

# Запуск тестов с отчётом о покрытии
poetry run pytest --cov=src

# Проверка стиля кода (flake8)
poetry run flake8 src tests

# Статическая типизация (mypy)
poetry run mypy src
