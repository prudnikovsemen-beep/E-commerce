# E-commerce

E‑commerce система на Python 3.12: модели товаров и категорий, загрузка данных из JSON, базовая бизнес‑логика и валидация.

Проект демонстрирует:
- Устойчивую обработку некорректных данных (пропуск битых записей без падения).
- Полное покрытие тестами (pytest) с покрытием >98%.
- Строгую типизацию (mypy) и соответствие PEP 8 (flake8).

## Возможности

- Загрузка категорий и товаров из JSON‑файла.
- Автоматическое пропускание некорректных записей (неверные типы, отсутствие обязательных полей).
- Модели `Product` и `Category` с базовой логикой (подсчёт общей стоимости).
- Подсчёт статистики по категориям и товарам.

## Установка и запуск

### Требования
- Python 3.12
- Poetry для управления зависимостями

### Установка зависимостей

poetry install

## Запуск проекта
poetry run python -m src.main

## Тестирование и качество кода
Все тесты проходят, покрытие кода >98%. Качество кода поддерживается на высоком уровне.

### Запуск тестов с покрытием
poetry run pytest --cov=src --cov-report=term-missing


## Проверка стиля (PEP 8)
poetry run flake8 src tests

## Статическая проверка типов
poetry run mypy src
