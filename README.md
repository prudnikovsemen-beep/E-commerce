# E-commerce

E‑commerce система на Python 3.12: модели товаров и категорий, загрузка данных из JSON, базовая бизнес‑логика и валидация.

Проект демонстрирует применение ООП в реальном сценарии: инкапсуляцию данных, работу с приватными атрибутами, использование `property` и сеттеров с валидацией, а также класс-методы.

## Что реализовано в рамках ДЗ 14.2

- **Инкапсуляция**: приватные атрибуты (`__price` в `Product`, `__products` в `Category`).
- **`property` и сеттеры**: свойство `price` с валидацией (запрет на ≤ 0) и подтверждением при снижении цены.
- **Класс-метод**: `Product.new_product()` для создания объекта из словаря.
- **Методы категорий**: `add_product()`, строковое представление товаров через `products` (property), подсчёт количества товаров через `product_count`.
- **Обработка некорректных данных**: при загрузке из JSON битые записи пропускаются без падения программы.

## Возможности

- Загрузка категорий и товаров из JSON‑файла.
- Автоматическое пропускание некорректных записей (неверные типы, отсутствие обязательных полей).
- Модели `Product` и `Category` с базовой логикой (подсчёт общей стоимости, вывод списка товаров).
- Подсчёт статистики по категориям и товарам.
