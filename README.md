# Виджет банковских операций

Виджет для отображения последних успешных банковских операций клиента с возможностью фильтрации, сортировки и маскировки конфиденциальных данных.

## Описание проекта

Проект представляет собой Python‑библиотеку для работы с банковскими операциями. Основные возможности:

* маскировка номеров банковских карт и счетов;
* фильтрация операций по статусу (выполненные, отменённые и т. д.);
* сортировка операций по дате (по возрастанию/убыванию);
* преобразование форматов даты;
* обработка данных в едином интерфейсе;
* чтение и валидация JSON/CSV/Excel‑файлов с транзакциями;
* конвертация сумм транзакций в рубли по актуальным курсам через внешний API.

## Новые возможности (homework 13.2)

### Чтение данных из CSV и Excel

В текущей итерации добавлена поддержка чтения транзакций из CSV и Excel:

- **Единый интерфейс**: функции `read_operations_from_csv` и `read_operations_from_excel` возвращают одинаковый тип — `List[Dict[str, Any]]`. Это позволяет использовать одну и ту же логику обработки (фильтрация, сортировка, маскировка) без изменений.
- **CSV**: используется `csv.DictReader` для парсинга строк в словари.
- **Excel**: используется `pandas.read_excel` для загрузки таблиц.
- **Обработка ошибок**: при невозможности прочитать файл или несоответствии формата возвращается пустой список `[]` — это сохраняет устойчивость приложения.
- **Тестирование**: все сценарии замоканы через `unittest.mock` (включая `mock_open` для CSV и `patch("pandas.read_excel")` для Excel). Проверены случаи пустого файла, ошибки чтения и некорректного формата.

### Логирование (наблюдаемость и отладка)

Добавлена полноценная система логирования для ключевых модулей:

- **Отдельные логеры** для `utils`, `masks`, `file_reader`, `external_api` (через `logging_config`).
- **Формат логов**: timestamp, имя модуля, уровень, сообщение — для быстрой диагностики.
- **Уровни логирования**: DEBUG+; успешные операции — INFO, предупреждения — WARNING, ошибки — ERROR с `exc_info=True`.
- **Вывод**: логи пишутся в папку `logs/` (файл перезаписывается при каждом запуске).
- **Цель**: сделать поведение системы прозрачным для отладки и мониторинга, не меняя публичный API функций.

## Модуль `src/utils.py`

Модуль для безопасной работы с JSON‑файлами.

**Функции:**

- `read_operations(file_path: str) -> List[Dict[str, Any]]` — читает JSON‑файл с операциями и возвращает список транзакций. Корректно обрабатывает случаи: файл не найден, пустой файл, невалидный JSON, ошибки чтения (включая `OSError`). Во всех проблемных случаях возвращает пустой список `[]`.

**Особенности реализации:**

- проверка существования файла перед чтением;
- обработка `json.JSONDecodeError` и `OSError` с логированием ошибок;
- возврат пустого списка вместо выброса исключений (для устойчивости в продакшен‑сценариях);
- логирование на уровнях DEBUG (вызов), INFO (успех), WARNING (файл не найден/пустой), ERROR (ошибки чтения/парсинга).

## Модуль `src/file_reader.py` (новое)

Модуль для чтения транзакций из CSV и Excel.

**Функции:**

- `read_operations_from_csv(file_path: str) -> List[Dict[str, Any]]` — парсит CSV‑файл через `csv.DictReader`.
- `read_operations_from_excel(file_path: str) -> List[Dict[str, Any]]` — загружает Excel через `pandas.read_excel`.

**Особенности реализации:**

- единый тип возврата для всех форматов — список словарей;
- при ошибках чтения или неверном формате возвращается `[]`;
- добавлены логи на уровнях INFO (успешное чтение), WARNING (пустой файл), ERROR (не удалось прочитать);
- в тестах полностью замоканы `open` (CSV) и `pandas.read_excel` (Excel) — это позволяет проверять логику без реальных файлов.

## Модуль `src/external_api.py`

Модуль для конвертации валют через внешний API.

**Функции:**

- `get_exchange_rate(currency_code: str) -> float` — получает актуальный курс валюты. **Проверка наличия `EXCHANGE_API_KEY` оставлена в коде** как элемент безопасной работы с секретами. При отсутствии ключа функция сразу возвращает `0.0`, не делая сетевых запросов.
- `convert_transaction_to_rub(amount: float, currency_code: str) -> float` — конвертирует сумму транзакции в рубли по текущему курсу. При отсутствии курса или ошибке API возвращает `0.0`.

**Тестирование и устойчивость:**

- В тестах `os.getenv` и `requests.get` полностью замоканы: это позволяет проверять логику при наличии и отсутствии ключа, не завися от реального `.env`.
- Обработка сетевых ошибок, таймаутов и HTTP‑ошибок.
- Безопасный возврат дефолтного значения вместо падения приложения.
- Исправлена типизация для `mypy`: `params` и `headers` явно типизированы.
